# SWYNEX Task 4 – Final Data Analytics Project Report

## 1. Introduction
This project focuses on analyzing online retail transaction data to understand sales performance, product demand, and country-wise sales distribution.

## 2. Objective
- Clean and prepare raw transaction data.
- Perform exploratory data analysis.
- Identify top-performing products and countries.
- Build an interactive Power BI dashboard.
- Present meaningful business insights.

## 3. Data Cleaning
The dataset was processed using Python and Pandas. Missing product descriptions and exact duplicate records were handled, zero unit-price records were removed, and invoice dates were converted into datetime format. Negative quantities were retained because they may represent returns or cancellations.

## 4. Exploratory Data Analysis
Excel was used to analyze sales, quantities, country-wise performance, and top products. A Sales column was created using Quantity multiplied by UnitPrice.

## 5. Dashboard Development
An interactive dashboard was created in Power BI with KPI cards, product performance charts, a country sales chart, a daily sales trend, and Country and Description slicers.

## 6. Key Findings
- Total sales in the analyzed dataset were approximately 338,412.84.
- Total quantity was 156,114.
- The United Kingdom contributed approximately 91.37% of recorded sales.
- REGENCY CAKESTAND 3 TIER was the top product by sales value in the analysis.
- The dataset covers December 2010, so the daily trend should not be interpreted as a multi-month trend.

## 7. Tools Used
Python, Pandas, Microsoft Excel, Power BI, and GitHub.

## 8. Conclusion
This project demonstrates the data analytics workflow from cleaning and exploratory analysis to dashboard creation. It helped develop practical skills in data preparation, visualization, and communicating business insights.
