# SWYNEX Task 4 – Final Data Analytics Project

## Project Title
Online Retail Sales Analysis

## Internship Task
SWYNEX Internship – Task 4: Final Data Analytics Project

## Problem Statement
The objective of this project is to analyze online retail transaction data, identify sales patterns, understand product performance, and generate useful business insights.

## Dataset
UCI Online Retail Dataset containing invoice numbers, product descriptions, quantities, unit prices, invoice dates, customer IDs, and countries.

## Project Workflow

### Task 1: Data Cleaning and Preparation
- Identified missing values and duplicate records.
- Removed rows with missing product descriptions.
- Removed records with zero unit price.
- Converted invoice dates into datetime format.
- Retained negative quantities for return and cancellation analysis.

### Task 2: Exploratory Data Analysis
- Analyzed sales and quantities.
- Identified top-performing products.
- Compared sales across countries.
- Performed exploratory analysis using Excel.

### Task 3: Interactive Dashboard
- Created KPI cards for sales, quantity, unique invoices, and unique product descriptions.
- Created charts for top products, country sales, and daily sales trends.
- Added Country and Description slicers.

## Key Business Insights
- The United Kingdom contributed the largest share of sales in the analyzed dataset.
- REGENCY CAKESTAND 3 TIER was the highest-selling product by sales value in the analysis.
- Negative quantities may represent product returns or cancellations.

## Tools Used
- Python and Pandas
- Microsoft Excel
- Power BI
- GitHub

## Conclusion
This final project combines data cleaning, exploratory data analysis, and interactive dashboard development into a complete data analytics case study.
